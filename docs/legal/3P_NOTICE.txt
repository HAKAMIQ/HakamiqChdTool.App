CsoKit
--------------------------------------------------------------------------------

CHD Tool includes CsoKit 0.6.6 to handle PSP CSO and ZSO files.

CsoKit can read CSO file details, check a CSO file, and make a
temporary ISO before chdman creates the CHD.

Related file:
CSOKIT_NOTICE.md

Upstream:
https://github.com/HAKAMIQ/CsoKit

igir
--------------------------------------------------------------------------------

CHD Tool can optionally use the unmodified igir v5.8.1 executable for
read-only DAT matching and CSV reports. The app invokes only `igir report`.
The executable is fetched from the official upstream release and SHA-256
verified before use. It never moves, copies, renames, or deletes library files.

License: GPL-3.0-or-later. See IGIR_NOTICE.md and IGIR_GPL-3.0.txt.
Upstream: https://github.com/emmercm/igir/tree/v5.8.1
Corresponding Source: igir-5.8.1-source.tar.gz, published next to the release
ZIP (SHA-256 18742ACA59AAD2D562B25645EC6DAE728A9BF234AE597E2BD162ABCC992BEF46).
